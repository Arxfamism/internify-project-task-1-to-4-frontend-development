# internify-project-task-1-to-4-frontend-development

Completed my Frontend Development Internship projects at Internify.

This repository contains four frontend development tasks built using HTML, CSS, and JavaScript. Each task focuses on practical web development skills, responsive design, JavaScript functionality, and user interaction.

Task 1: Responsive Personal Portfolio Website
- Created a responsive portfolio website.
- Added Home, About, Skills, Projects, and Contact sections.
- Implemented skill progress bars, project cards, social icons, and a contact form.
- Added smooth scrolling, animations, hover effects, and mobile responsiveness.

Task 2: Interactive Pricing/Product Cards
- Designed four pricing cards with modern UI.
- Added Monthly/Yearly pricing toggle using JavaScript.
- Implemented All, Basic, and Premium category filters.
- Added Most Popular plan badge, hover animations, and interactive CTA buttons.
- Designed a responsive pricing layout using CSS Grid.

Task 3: Multi-Page Website with Form Validation
- Created Home, About, and Contact pages.
- Added a responsive mobile hamburger navigation menu.
- Implemented JavaScript form validation.
- Added inline error messages and success notifications.
- Implemented Dark Mode and Light Mode using localStorage.

Task 4: Dynamic Web App with Live API Data
- Developed a Country Explorer web application.
- Integrated live country data using JavaScript.
- Added country search functionality, loading state, and error handling.
- Displayed country information in styled cards, including flag, capital, region, population, currency, and languages.
- Added recent search functionality using localStorage.
- Designed a responsive and animated user interface.

Technologies Used:
HTML5, CSS3, JavaScript, REST API, DOM Manipulation, LocalStorage, CSS Grid, Flexbox, and Responsive Web Design.

This internship helped me improve my frontend development, JavaScript logic, API integration, UI design, and problem-solving skills.
